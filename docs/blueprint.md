# **App Name**: PalmVerse

## Core Features:

- User Authentication: User Authentication via OTP to mobile number.
- Palm Image Upload: Image upload for both palms.
- User Info Collection: Collect user's date of birth, place of birth, time of birth and dominant hand information.
- AI Palm Reading: Generates personalized palm reading reports from palm images using generative AI, focusing on user-selected categories, acting as a tool during the palm reading creation.
- Report Display: Displays a structured and detailed palm reading report to the user.

## Style Guidelines:

- Primary color: A mystic purple (#A084CA) evoking spirituality and insight.
- Background color: Light, desaturated lavender (#F4F2FF), maintaining a focus on content.
- Accent color: A serene blue (#8CB9BD), providing balance.
- Headline font: 'Playfair', serif, elegant with thin-thick lines, and 'PT Sans', sans-serif, for the body to keep readability in longer texts.
- Simple line icons that relate to palmistry and astrology.
- Clean layout with generous whitespace. Clear separation of sections, ensuring that palm readings are easy to understand.
- Smooth transitions and loading animations to provide a polished user experience.
